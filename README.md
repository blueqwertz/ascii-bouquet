# ASCII Bouquet

Spinning 3D ASCII flower bouquet for the terminal — pure bash + awk, runs on a stock Mac (no Python needed).

> **Credits:** This is a bash/awk port of [**Ascii-Flower-Bouquet-**](https://github.com/alishsharma17/Ascii-Flower-Bouquet-) by [Alish Sharma](https://github.com/alishsharma17) ([@alishsharma on TikTok](https://www.tiktok.com/@alishsharma)). All the design, scene and rendering ideas are from the original Python version. Licensed under MIT, © 2026 Alish Sharma — see [LICENSE](LICENSE).

## Run it

```bash
curl -fsSL https://raw.githubusercontent.com/blueqwertz/ascii-bouquet/main/bouquet.sh | bash
```

Press `Ctrl+C` to stop. Bigger terminal window (or zoom out with `Cmd -`) looks better.

## Customize

Edit `MESSAGE`, `SPIN_SPEED`, `TILT`, `CAM_DIST`, `NUM_HEARTS` and `FPS` at the top of `bouquet.sh`.
